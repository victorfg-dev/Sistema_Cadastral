# Sistema Cadastral

Esse programa cadastra, deleta e busca usuários armazenados em um JSON.

## Funcionalidades (versão 1)
- Menu de cadastro;
- Opção de saída;
- Busca de cadastros;
- Inserir cadastros novos;
- Deletar cadastros.

## Objetivos
- Aplicação de conhecimentos em programação e prática do uso de vetores;
- Aproximação com o mundo real a partir dos aprendizados acadêmicos e independentes;
- Aplicação de conhecimentos em versionamento e construção de protótipos.

## Requisitos
- Interpretador para Python, como PyCharm ou afins;
